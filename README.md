# FoZ SoundPro — Beatmaker AI Studio

Entorno modular de producción musical asistida por IA.

## Objetivos

- Producción de Rap, Hip Hop, Trap y música electrónica.
- Grabación, edición, mezcla y exportación de audio.
- Generación y edición de patrones MIDI.
- Integración opcional con modelos de IA locales y proveedores gratuitos.
- Compatibilidad objetivo con macOS y Windows.
- Equipo de destino: Intel i5 de 7.ª–10.ª generación,
  8 GB de RAM y gráfica Intel integrada.

## Principios

- Reutilizar software de audio existente.
- Priorizar herramientas gratuitas y de código abierto.
- Separar el código del contenido musical.
- Verificar licencias, requisitos y compatibilidad antes de instalar.
- No realizar acciones destructivas ni instalar componentes sin aprobación.
- Mantener pruebas y documentación actualizadas.
