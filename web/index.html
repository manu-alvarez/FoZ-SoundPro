Cómo funciona:

  • Es multitáctil: funciona con dedos en pantalla táctil o arrastrando el ratón.
  • El FX se aplica al bus master del beat (todas las voces), no al instrumento individual.
  • El eco se re-sincroniza al BPM del proyecto en cada cambio de tempo.
  • El estado queda guardado en el proyecto (.foz / LocalStorage) y opcionalmente horneado en el export WAV.

💻 Instrucciones multiplataforma (Windows · macOS · Linux)

1 — Uso autónomo sin instalación (las tres plataformas):

  1. Descomprime FoZ_SoundPro_Portable_v1.1.zip en cualquier carpeta.
  2. Lanza el archivo de arranque de tu sistema: Windows → start_windows.bat (doble clic) · macOS → start_mac.sh (doble clic o sh start_mac.sh) · Linux → sh start_linux.sh (o chmod +x start_linux.sh && ./start_linux.sh).
  3. El lanzador arranca un servidor web local libre de colisiones, y abre el estudio en el navegador.
  4. Sin estas herramientas, todo funciona igual a coste 0 y sin conexión: síntesis de 16 voces, secuenciador 16/32/64 pasos, Trackpad FX, grabación sobre beat, bases importadas y exports WAV/MIDI.

2 — Conexión opcional con IA (Ollama):

  • Instala Ollama en cualquiera de las tres plataformas desde ollama.com (no la empaquetamos: descarga del fabricante).
  • Inicia el puente local: python3 scripts/automation/local_bridge.py (Windows: python scripts\automation\local_bridge.py). Es la ruta recomendada: el puente traduce Ollama ↔ navegador sin tocar CORS.
  • Alternativa directa: en Ollama define OLLAMA_ORIGINS permitiendo tu origen local para que el navegador pueda leer los modelos directamente (útil en red Tailscale).
  • Si falta un modelo, descárgalo desde esta misma página con el botón Descargar (pull) de la tarjeta de arriba.

3 — Opcional LMMS (arreglos y mezcla multipista):

  • Si LMMS está instalado, el puente lo detecta automáticamente y esta tabla lo muestra.
  • Importa los archivos MIDI exportados en LMMS 1.2.2 para arreglos orquestales o mezcla multipista avanzada.
