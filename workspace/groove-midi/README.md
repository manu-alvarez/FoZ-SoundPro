# Fase B — Groove MIDI Dataset (Magenta) — Presets .foz (CC BY 4.0)
Fuente verificada: Google Magenta — Groove MIDI Dataset (magenta.withgoogle.com/datasets/groove)
Licencia: CC BY 4.0 © Google LLC
Contenido: 1.150 MIDIs, >22.000 compases de drumming anotado.
Nota: los archivos MIDI originales NO se empaquetan en Git ni en el ZIP.
Los presets `.foz` derivados incluyen esta atribución obligatoria.
Uso en la app: botón "📂 Kit (carpeta)" para importar carpetas de groove;
script `scripts/resources/import_groove_midi.py` convierte `.mid` a `.foz`.
